# 中文小模型 CPU 候选实测

## 决策

后续已收到麒麟1/2线程原始JSON并核验模型、样本哈希与识别结果一致性，见 [麒麟反馈与v2修复](PRIVACY_CONTEXT_V2.md)。麒麟第一轮P95分别为1.289/1.876 ms，尚未验证v2或服务共存负载；下文Windows数据保留为初测记录。

小模型在 Windows CPU 上可运行，资源开销值得带到麒麟复测；当前模型及简单实体策略**不适合直接启用为生产隐私门控**。没有切换默认配置或推送远程。

## 目标资源（用户截图提供，未在此处独立核查）

银河麒麟 V11 (2603)，VMware，x86_64，4 vCPU / 8 GB RAM；底层宿主为 i9-14900HX。截图时可用约 1.7 GiB、已用 swap 约 5.8 GiB。不能按宿主全部核心算预算；swap 已占用也不等于测量时持续换页，须观察 vmstat。

用户提供的知识检索口径为查询 Embedding 加向量检索 ≤500 ms，截图中已有的 12/19/35 ms、HTTP 平均56/最大72 ms 等均属于历史小样本记录，本轮未复核。**本报告中的敏感检测时间另列**，不用于声称检索达标或 Recall@5 达标。

建议以 1～2 个推理线程开始目标机诊断，限制同时检测请求数为1；先确认真实资源再决定阈值。这是工程试验起点，不是赛题要求。本轮尚未实现生产请求队列或并发限制。

## 候选和实际环境

候选为 [MiniRBT 中文 NER 原模型](https://huggingface.co/IcyKallen/bert-mini-finetuned-ner-chinese) 的 [ONNX 量化导出](https://huggingface.co/TomatoMTL/bert-mini-finetuned-ner-chinese-onnx)，固定 revision `2e6990291be3ec0407ef0d559e8346893b8ff4e9`。权重实测12,606,755字节，标签为PER/ORG/LOC/MISC；训练数据说明不完整。没有使用其模型卡分数替代本项目测试。

备选 [CKIP Tiny](https://huggingface.co/ckiplab/bert-tiny-chinese-ner) 官方说明偏繁体中文且标注GPL-3.0，本轮未下载或测试。没有把未经实测的其它模型列为达标方案。

实际运行环境：Windows 11、Python 3.12.7、ONNX Runtime 1.22.1、CPUExecutionProvider。运行依赖安装在项目 tmp/privacy-runtime，未改变主环境依赖；模型位于 tmp/privacy-model-mini。

| 场景 | 推理线程 | 热推理中位/P95/最大 ms | 末尾进程RSS MiB | 导入和加载 ms |
|---|---:|---:|---:|---:|
| 仓库脚本，导入现有规则模块 | 1 | 1.113 / 1.499 / 9.145 | 107.82 | 614.31 |
| 仓库脚本，导入现有规则模块 | 2 | 1.015 / 1.408 / 9.285 | 109.52 | 881.99 |
| 独立测试包，加载冻结规则JSON | 2 | 1.099 / 1.398 / 1.576 | 89.07 | 404.03 |

每项140次短文本热调用，含分词/模型/解码。RSS是末尾采样而非峰值；独立包未导入项目其它模块，因此进程RSS更低。线程数限制不等于模拟了4 vCPU虚拟机。以上全部是Windows候选测试，不是麒麟结果，也没有测并发/长文档/持续运行。

## 识别效果

新增28条虚构诊断文本，其中16条含17个敏感片段，12条正常文本。标注要求完整覆盖敏感片段，地址仅遮盖城市不算成功。

| 策略 | 完整覆盖敏感片段 | 被误遮盖的正常文本 |
|---|---:|---:|
| 现有规则匹配位置 | 5/17 | 1/12 |
| 模型PER/LOC实体 | 7/17 | 2/12 |
| 规则位置与模型位置并集 | 12/17 | 3/12 |

这些是诊断位置指标，规则位置来自原文正则匹配并集，并非完整入库/API测试。多遮盖字符可能包含“密码”等字段前缀。诊断集没有独立盲测，不能作为真实用户总体准确率。

组合仍漏掉网名、隐式地址、空格分隔手机号、汉字手机号、生日；公开城市和项目名称仍有模型误识别，会议日期有规则误伤。旧12条基础回归通过与这些更难的新样本结果并不矛盾。
