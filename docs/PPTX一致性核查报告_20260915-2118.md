## 二、备注项（非错误，可选优化）

### ⑤ 向量维度 768 vs config 默认 1024 —— 备注【非错误】
- PPTX（Slide 6/11/12）：**768 维**（kylin 严格模式）
- 权威：`configs/default.yaml:132` `vector_dim: 1024`（注释「真实维度（真机探测后覆盖）」）；`/health`（测试结果.md）真机 = **768**
- 结论：**PPTX 正确**（真机值）；config 默认 1024 是占位符，运行时被覆盖为 768
- 建议：无需改 PPTX；可选将 config 默认 1024 改为注释说明或 768，避免阅读混淆
