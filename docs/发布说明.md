# 发布说明

本仓库是赵琳在麒麟原版基线上整理的 Windows 工程化版本，用于本机安装、memory + hash 接线，以及 GitHub Actions 的 Windows 测试。麒麟真机验收仍走 `requirements.txt` 与 `scripts/*.sh`。

| 项 | 内容 |
|---|---|
| 上游仓库 | 阿里云 Codeup `git@codeup.aliyun.com:6a60620d8c4f3693e22016a1/MOKOA.git` |
| 原版快照 | <https://github.com/IweirdoI/mokoa-kylin>，基线 `220bdd1` |
| 许可证 | 随上游保留 Apache License 2.0（见根目录 `LICENSE`） |
| 本人分工 | 偏好记忆 `src/preference/`（团队标识 `26a9835a`）。模块产出 `MemoryEntry`，不写 Milvus，不直接调用 `create_memory`。 |
| 方案正文 | [赵琳-偏好记忆整体技术方案.md](../赵琳-偏好记忆整体技术方案.md) |
| 相对原版增加 | `requirements-windows.txt`、`pyproject.toml`、`scripts/setup_windows.ps1`、`scripts/dev_windows.ps1`、`scripts/windows_env.ps1`、`docs/WINDOWS.md`、CI 作业 `test-windows`。特征覆盖脚本改用 `platform.platform()`。FLOW 持久化脚本在 Windows 上直接退出。语料测试在缺少 pyarrow 时跳过。 |

Windows 上的 hash 或 BGE 结果只说明开发环境，不作为银河麒麟 SDK 的验收数字。团队其余模块仍按根目录 `README.md` 的分工表，沿用仓库里的原有标识。
