## 六、注意事项

- 版本号一旦发布不得修改；若要调整规则，未推送的 tag 可删除后重打，已推送的须团队协商。
- 后续新提交继续补标：`python scripts/auto_tag_semver.py --apply --skip-existing`；不带 `--skip-existing` 时脚本会因同名 tag 已存在而拒绝执行，避免覆盖已发布版本。
- 如需 `v` 前缀，使用 `--prefix v`。
- 脚本修正（2026-09-15）：破坏性变更原按“正文包含 `BREAKING CHANGE` 字样”判断，会把“只是提到该词”的提交误判为 MAJOR（打标脚本自身的提交 `dfe3010` 曾被判成 `1.0.0`）；已改为只识别 Conventional Commits 的页脚写法（行首 `BREAKING CHANGE:` / `BREAKING-CHANGE:`）。修正后重新全量 dry-run，原有 197 个映射逐一未变。
