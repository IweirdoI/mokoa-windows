- semantic_detection.enabled 仍为 false；规则模式不承诺识别任意姓名、地址、昵称或隐含身份。
- 尚未选定、下载或评估真实轻量模型；语义测试使用模拟响应。当前检测适配器仍使用现有 LM Studio 原生接口，不能直接假设其它模型服务兼容。

- 摄取 staging 审计与 raw 归档仍使用规则脱敏，早于语义入库检查。语义失败不等于没有产生 staging 记录；本轮没有改变其保留策略。正式隐私交付仍需单独审核这条路径、metadata 及所有外部模型调用，不能宣称全链路已完成语义保护。
- Windows 结果不替代麒麟 SDK、目标 CPU/内存和文件权限验收。
