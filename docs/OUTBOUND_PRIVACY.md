# 模型外发脱敏

普通对话、SSE 流式对话和偏好抽取均在调用模型 SDK 前执行
`src.security.outbound.protect_payload`。检查覆盖消息正文、历史消息、
工具返回内容和工具定义；结构化凭证字段整体替换，嵌套文本使用共享规则脱敏。
该出口检查不记录原文映射，也不修改调用方输入。

已有规则覆盖 SSH 私钥（包括缺失结束标记的文本）、仓库访问令牌、
手机号和身份证号等。原始图片、音频和文件块不能通过文本接口直接外发。
原图视觉调用和接收原文的语义检测只允许本机回环端点，禁用环境代理。

这提供的是已识别敏感内容的外发保护。无法保证识别任意商业秘密、
经过编码或拆分的秘密，亦不能保证本机模型服务不会自行转发数据。
供应商用于请求认证的 API key 仍需交给对应服务，不属于消息正文脱敏范围。

回归验证（仓库虚拟环境，无真实供应商请求）：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_outbound_privacy.py tests/test_agent.py tests/test_privacy_baseline.py -q
```

测试在 SDK 边界捕获请求，验证同步与流式发送内容，另验证偏好抽取、
嵌套凭证、附件拦截和远程原文检测拦截。测试数据均为合成内容。
