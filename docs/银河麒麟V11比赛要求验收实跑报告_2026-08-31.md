1. **运行环境**：必须 `scripts/run_host_py.sh` + 宿主机 3.12 + 显式麒麟 `.so`。依赖走清华源。

3. **质量门**：`occurrence_count=1` 的行为默认拒；演示用 ≥5。  
4. **LLM 抽取未启用**：`degraded_to_rules=true`。  
5. **知识默认进不了召回**：heat = 访问 + 质量×5 + 置信度；工具结果约 4.7，差一次 `/touch`。`/recall` 不查短期。  
6. **未过滤召回会夹带已 supersede 的旧偏好**；评测应 `memory_type=knowledge` 或看画像 `is_latest`。  
7. **旧 API 进程**：18080 / 18082 仍在跑旧代码；知识过滤与跨场景以 **18083** 为准。  
8. **`configs/default.yaml` 明文 LM Studio key**，提交前删除。  
9. **评测规模小**，不能把 5 条 100% / 0.04ms 写成官方大集成绩。
