## 四、可复现性声明与方法学
- 所有抽测均使用 `random.Random(seed)` 无放回抽样, 选中的全局/行索引记录在 `sampled_indices` (JSON) 中, 他人用相同 seed 可复现完全相同样本。
- 检索评测走 MOKOA 自有 `create_memory`/`query_memory` 通道, query 用本地 BGE-M3 编码, 进程内客户端做真实余弦相似度排序, 直接对应赛题 (3)/(7)。
- 入库测试对每条样本经 MemoryPolicy 质量门控 + 真实编码, 记录分类器判定分布。
- 局限性: 检索语料为抽样子集(非 8.8M 全集), 指标用于验证链路与口径; 全量数字需以真机/完整语料复核。
- 数据集覆盖: 本次对 DailyDialog / MS MARCO / MultiWOZ / DIALOGBENCH / PersonaChat / ToolBench / BPMN 共 7 个数据集做了抽测。TREC DL 的 queries+qrels 已下载落盘 (git/TREC), 但其 qrels 引用的 passage 来自 MS MARCO 8.8M 全集, 而本次下载的 HF `microsoft/ms_marco` 子集不含该全集; 故检索评测改用 MS MARCO v1.1 validation 自带的 is_selected 相关性标注(同为真实人工标注), 保证评测自包含且可复现。

## 五、关键发现与改进建议
- **编排器入库通过率低**: process_input 端到端仅接受 1/5 (接受率 0.2); 入库管线质量门控/格式要求偏严, 建议核查输入形态与 MemoryPolicy 阈值。
