## 5. 口径、未测与优化方向

- 知识召回对外写 **抽样 MS MARCO Recall@5**。TREC Recall@5 因每问正例很多、top5 物理上限，不能横比 85%。
- TREC 为 judged 正例 pid + 2000 随机干扰，**不是**官方 8.8M nDCG。
- 开放域偏好以语义判卷为公平口径；token 覆盖仅参考。
- 封闭键 fusion 本轮 `restrict_llm_to_known_keys=True`（仅评测，产品默认关）。
- 对话 Hit@5 是记忆 id 自检索，不是 MultiWOZ 槽位 / ToolBench 工具选择 / DailyDialog BLEU。
- 未测：HTTP `/ingest`+`/recall`、麒麟持久化集合、564k 全量、TREC 8.8M 全库、BPMN、官方 LLM-judge。
- 封闭键全集只有 35 条，无法按 1.5× 扩样本；已用全集。
- TREC 第一次编码 9707 段时麒麟 embedding 超时（`Timeout was reached`），已用同一 seed/rc 重跑成功（`retrieval_20260915-140209.json`），合并进 `retrieval_20260915-140210.json`。MS MARCO 数字仍来自第一次成功的 `retrieval_20260915-134740.json`。
