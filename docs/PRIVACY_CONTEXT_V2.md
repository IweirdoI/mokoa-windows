## 小体积复测包

`artifacts/privacy-cpu-probe-context-v2.zip` 只含脚本、规则、样本、说明和许可文本，不含模型或运行库。原9 MB包保持第一轮冻结状态，不用重新下载权重。

将本小包解压到**新目录** `/tmp/mokoa-privacy-context-v2`，复用上次已准备的模型和虚拟环境：

```bash
cd /tmp/mokoa-privacy-context-v2
/tmp/mokoa-privacy-probe/.venv/bin/python scripts/privacy_ner_eval.py \
  --model-dir /tmp/mokoa-privacy-probe/model \
  --rules-file rules.json --threads 1 --output result-context-v2.json
```

若上次重建使用了不同目录，替换命令中的Python和model路径。不要把旧版rules.json用于这次结果。本次报告增加rules_sha256区分规则版本。

这个包只诊断候选识别，不改生产配置；无需为重复测试重启现有服务。并发共存测试仍待真实机器安排，规则与模型合并的生产策略仍待独立样本验证。
