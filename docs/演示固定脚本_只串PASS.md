## 0. 演示前检查（环境）

- 后端：`uvicorn api.server:app --host 127.0.0.1 --port 18080`，按 `docs/测试结果.md` 第 9 节导出 `OS_AGENT_*` 环境变量（kylin 后端、768 维、严格模式）。
- 前端（可选）：`cd frontend && npm run dev -- --host 127.0.0.1 --port 5173`，确认「实时 API 已连接」。
- 用户：统一使用 `demo_user_a`（映射 `fcov_a_...`），切换隔离演示时再用 `demo_user_b`。
- 不杀 18080 演示进程做持久化演示；FLOW 重启用独立端口 18089 另起进程。
